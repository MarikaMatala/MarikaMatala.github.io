# Configuration templates

<!-- Last updated: 2026-11-06 20:27 (Europe/Helsinki). -->

The files in this directory are examples, not active configuration for the current browser demo.

## Files

- `demo.example.json` is valid JSON with fictional values and `_comment` fields. JSON does not support JavaScript-style comments, so the explanatory notes are represented as ordinary fields.
- `app.example.js` uses `/* ... */` comments to explain each setting. It is not loaded by the current website.

## How to adapt

1. Read the comments before changing a value.
2. Replace only the example values you actually need.
3. Keep provider credentials in a local `.env` file or deployment secret manager, never in these public examples.
4. Do not commit a real `.env` file.
5. Do not add personal CV data or real job applicant information to sample configuration.

The current GitHub Pages demo does not import either template.
