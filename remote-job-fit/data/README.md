# Data directory

No third-party dataset is currently stored in this directory. The current demo uses its own small, manually curated keyword vocabulary and fictional example vacancy text.

## Before adding an external dataset

1. Identify the exact dataset and version.
2. Read the licence for that exact release and check any third-party exceptions.
3. Confirm that commercial use, modification and redistribution are allowed for the intended use.
4. Record the dataset name, version, download date, source URL, licence URL and any required attribution.
5. Record all transformations, translations, filtering and other modifications.
6. Keep the source attribution alongside the imported data and in the root `THIRD-PARTY-NOTICES.md`.
7. Do not add CVs, personal data, private job ads or scraped content without a valid legal basis and permission.

## Sources with documented reuse terms

- **ESCO**: the European Commission permits reuse free of charge subject to acknowledgement. If integrated into an application, include the required statement: "This service uses the ESCO classification of the European Commission." Clearly identify any modified or adapted ESCO data.
- **Wikidata structured data**: CC0. Check the licensing page for the distinction between structured data and text on other Wikidata pages.
- **O*NET Database**: CC BY 4.0 for the covered database content. Credit the O*NET 31.0 Database and USDOL/ETA, link the licence and indicate modifications. Check the database's third-party exceptions before reuse.
- **Wikipedia text and Queast taxonomy releases**: CC BY-SA 4.0 where that licence is specified. Reuse requires attribution and ShareAlike compliance. Do not mix these materials into the project without recording and meeting those conditions.

These notes are not a substitute for checking the exact source release and licence before downloading or importing it.
