# Portfolio images | Portfolion kuvat

This directory contains the local image and document assets used by the Portfolio 2026 website. Using local files means the portfolio does not depend on a separate repository being public.

## Assets / Sisältö

- `Sana-Vapaa-tapahtumajuliste.pdf` — event poster created as part of the Luotsaamo project run by Jyvässeudun 4H-yhdistys.
- `Video ja valokuvaesittely PDF.pdf` — portfolio from the vocational qualification in audiovisual communications.
- `omakuva.png` — profile photo.
- `omena2.png` — visual design coursework from JAMK.
- `peli.jpg` — animation exercise from a game-industry course.
- `kaivo.jpg` — 3D well model from a game-industry course.
- `android-kurssin tehtavien kuvia/` — screenshots from Android coursework.
- `creative-samples/` — selected additional creative and 3D samples.
- `wi-branding/` — WI and WIMMA Capstone branding samples.
- `antique-paper-texture.svg` and `metal-rose-sigil.svg` — custom SVG decorative artwork generated with ChatGPT assistance for the portfolio.
- `../The-Cultured-Vault-demo/icons/vault-icon.svg` and `vault-maskable.svg` — custom SVG app icons generated with ChatGPT assistance for the demo.
