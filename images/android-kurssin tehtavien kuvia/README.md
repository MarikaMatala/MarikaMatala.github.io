# Android-kurssin tehtävien kuvat

Lisää tähän kansioon Android-kurssin tehtävistä otetut kuvat.

Kun kuvat ovat kansiossa, niitä voidaan käyttää portfolion kuvakarusellissa. Säilytä kuvatiedostojen nimet selkeinä ja käytä mielellään pieniä kirjaimia sekä väliviivoja, esimerkiksi `android-tehtava-01.png`.
