# Security Policy

## Scope

This repository contains a static portfolio website published with GitHub Pages. It uses HTML, CSS and client-side JavaScript; it is not intended to provide an authenticated service or to store visitor accounts.

The website intentionally publishes professional contact links and selected portfolio material. Do not use public issues to share private information, account details, unpublished work, credentials or personal data.

## Third-party resources

Some pages may load third-party resources, such as the PrismJS syntax-highlighting library from a public CDN. Review dependency versions and their licences before changing or adding external resources. Do not add API keys, access tokens or other secrets to client-side files: anything published with the site is visible to visitors.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue or pull request.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is unavailable, contact the maintainer privately through the contact options on the GitHub profile. Include the affected page or file, steps to reproduce, expected and actual behaviour, and potential impact. Do not include credentials or private personal information in the report.

## Contributions

Before submitting changes, check that no credentials, private data, unpublished personal material or unlicensed third-party assets are included. Run the repository's site validation script and review the rendered pages in a browser.
