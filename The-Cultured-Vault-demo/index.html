Demo limitations and privacy

This is a static browser prototype with a manually curated local catalogue. The instance owner rating is “Not rated yet” for every work, and no owner review text is prefilled. IMDb and Open Library are external lookup links only. No third-party ratings, reviews, descriptions, posters or covers are imported. Rotten Tomatoes links are omitted because its terms restrict deep links without prior written consent. Visitor suggestions are stored only in this browser and are not sent to the maintainer yet. User accounts, sign-in, shared comments and a server-side database are not implemented yet. Your demo review is stored only in this browser. Nothing is sent to a server or added to the GitHub repository. Do not enter sensitive or personal information.
