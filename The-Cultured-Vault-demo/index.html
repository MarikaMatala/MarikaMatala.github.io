Demo limitations and privacy

This is a static browser prototype with a manually curated local catalogue. The instance owner rating is “Not rated yet” for every work, and no owner review text is prefilled. IMDb and Open Library are external lookup links only. No third-party ratings, reviews, descriptions, posters or covers are imported. Rotten Tomatoes is reached through a Google site search because its terms restrict direct deep links. Visitor suggestions and ratings are stored only in this browser and are not sent to the maintainer. You can update your rating for a work. User accounts, sign-in, shared comments, shared ratings and a server-side database are not implemented yet. Nothing is sent to a server or added to the GitHub repository. Do not enter sensitive or personal information.
