IMDb

Each catalogue entry opens an IMDb title search using the work's title. The Vault does not scrape IMDb, call its data endpoints, store IMDb ratings, reproduce reviews or copy images.

IMDb's published guidance permits only limited use of its downloadable datasets under specific conditions. This demo does not use those datasets or rely on that permission.

Google site-search linkNo RT data import

Rotten Tomatoes

Each catalogue entry provides “Find on Rotten Tomatoes”. It opens a Google search restricted to Rotten Tomatoes pages; it does not link directly to an individual Rotten Tomatoes page. Visitors choose whether to open a result.

Rotten Tomatoes' Terms of Use, last updated 6 January 2026, say that linking to pages other than the homepage requires Fandango's prior written consent. The demo therefore does not create direct Rotten Tomatoes deep links.

No Tomatometer or Popcornmeter scores, reviews, descriptions, posters or stills are imported or reproduced.

Open Library

Book entries open an Open Library search. The demo does not query its API, download covers, copy book descriptions or import catalogue records.

The external search is opened only when a visitor chooses the link. Open Library's API guidance is provided for reference; this demo does not currently integrate the API.

CATALOGUE AND VISITOR DATA

What is stored in this demo

Catalogue entries

The catalogue is maintained as plain-text data in the project's JavaScript file. Entries may include a title, creator, year, media category, genre and country. The demo does not import third-party plot summaries, biographies, editorial descriptions or user-generated text.

Facts and collections can still be subject to database rights or source-specific restrictions. The project does not claim that every catalogue fact has been individually cleared by a rights holder. The MIT licence does not cover the underlying creative works.

Ratings and reviews

No third-party numeric ratings or review text are imported. The project owner's rating is shown as “Not rated yet”. Visitors can add or update their own demo rating and optional comment; these are stored only in that visitor's browser using local storage.

Work suggestions

Visitors can save suggested titles in their own browser. Suggestions are not transmitted to the maintainer, shared with other visitors or added to the public catalogue. This is a local prototype form, not a live submission service.

Images, logos and trademarks

The catalogue does not include third-party posters, covers, film stills, album artwork, game artwork or service logos. Service names appear only as plain-text references to identify external lookup destinations. No affiliation or endorsement is implied.

TECHNICAL STATUS AND LIMITATIONS

What is and is not implemented

  • The site is a static browser prototype hosted on GitHub Pages. It has no server-side application backend or database.
  • There are no user accounts, sign-in, cloud synchronisation, public community reviews or shared visitor submissions.
  • Visitor ratings, comments and suggestions remain in the current browser's local storage. Clearing browser data may remove them.
  • A web app manifest and service worker are present for app-shell metadata and basic same-origin caching. The app-install button and installation instructions are not offered while installation readiness remains unverified.
  • External lookup links open third-party services. Those services have their own terms and privacy practices; this project does not control them.
  • Before adding any new dataset, API, image or content source, verify the exact licence and permitted use for the specific material. Public availability alone is not permission to copy or republish it.

This register describes the current implementation as of 9 November 2026. It is a project transparency note, not legal advice or a guarantee that every catalogue entry is free of third-party rights. Re-check external terms before changing integrations.
